One pickup line a robot would use, 200 characters at most — a single directive,
resolved.

> My makers gave me one directive: find the human. I found you.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set).
